# Bataille Navale — JavaFleet

Ce dépôt contient le cahier des charges pour le projet JavaFleet, un jeu de bataille navale décrit dans `docs/cahier_des_charges.md`.

## Contenu
- `docs/cahier_des_charges.md` : spécification fonctionnelle et technique (règles du jeu, stratégies, exigences client/serveur et pistes d’extensions).

## Lancer le projet
Aucun code n’est fourni pour le moment ; démarrez en choisissant la pile (client JavaFX, serveur Java ou Python) décrite dans le cahier des charges, puis implémentez les règles indiquées.

## Base de données / SQL
Aucune configuration SQL n’est définie ou requise à ce stade. Vous pourrez ajouter une base de données plus tard (par exemple pour l’historique des parties ou les comptes utilisateurs) en fonction des besoins du serveur.
